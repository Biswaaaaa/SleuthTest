# minijavac

A tiny compiler for a small subset of Java, written in Python (no dependencies), for demo purposes.

```
source ──lexer──▶ tokens ──parser──▶ AST ──codegen──▶ stack bytecode ──VM──▶ output
```

All four stages live in `minijavac.py`:

1. **Lexer**: a single regex that splits the source into tokens.
2. **Parser**: recursive descent that builds an AST out of tuples.
3. **Code generator**: turns the AST into instructions for a stack machine and resolves local variable slots and jump targets.
4. **Virtual machine**: runs the bytecode with Java's 32-bit `int` semantics.

## Usage

```bash
python3 minijavac.py examples/Fib.java          # compile and run
python3 minijavac.py examples/Fib.java --dump   # show the generated bytecode
```

## Supported subset

- One class with `static` methods; `main` is the entry point. Recursion works.
- Types `int`, `boolean`, `String`, `void`.
- Statements: declarations, `=`, `+=`, `-=`, `*=`, `/=`, `++`/`--`, `if`/`else`, `while`, `for`, `return`, blocks.
- Expressions: `+ - * / %`, comparisons, `&& || !` (with short-circuit evaluation), and string concatenation.
- `System.out.println` / `System.out.print`.

Compile-time errors include undefined variables, unknown methods, wrong argument counts and syntax errors.
